# Hermit package index

Personal Hermit packages maintained by `nandiheath`.

Use this repository before the official package source only in repositories that consume these personal packages:

```hcl
sources = [
  "https://github.com/nandiheath/hermit-packages.git",
  "https://github.com/cashapp/hermit-packages.git",
]
```

`routerctl` releases are added automatically from `nandiheath/homelab-cli`. This repository intentionally does not mirror the official package manifests.
